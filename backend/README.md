# Project Management - Backend (Express + MongoDB)
```
npm install
npm run dev     # http://localhost:5000
npm test        # API tests (server must be running)
```
Endpoints: POST /api/auth/register | /login, GET/POST/DELETE /api/projects, GET/POST/PATCH /api/tasks, GET /api/users (manager)
Deploy on Render / Railway; use MongoDB Atlas for MONGO_URI.
